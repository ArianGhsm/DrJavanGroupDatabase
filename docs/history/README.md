# Superseded designs

`intelligence-v2/` documents the multi-source (PubMed / current web / official) router and the rule-based archive planner. Both were replaced by the archive brain described in [`../ai-pipeline.md`](../ai-pipeline.md): the bot now answers only from the group archive, and query understanding, relevance and synthesis are done by the LLM over reconstructed discussions instead of hand-written rules. These files are kept for history only.
